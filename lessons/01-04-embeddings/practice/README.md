## Эксперимент 1. ID — не вектор (10–15 минут)

```bash
uv run python $P/01_embedding_lookup.py
```

Смотри на три разных размера:

- в таблице `4` строки — четыре учебных токена;
- в каждой строке `3` координаты;
- последовательность из трёх ID даёт матрицу формы `(3, 3)`.

ID и числа таблицы придуманы вручную. Это **не настоящий токенизатор, не обученная модель и не доказательство смысловой близости**.

### Задание 1.1. Выбери другие строки

Замени в `main()` `ids = [0, 1, 3]` на `ids = [2, 0, 2, 3]`. Предскажи форму результата до запуска. Почему первая и третья строки совпадают?

### Задание 1.2. Два значения слова

Программа показывает «лук» рядом с «салат» и рядом с «тетива». Почему начальный вектор одинаков? На каком этапе настоящая модель должна учесть разницу?

Важно: в этой игрушке нет слоёв внимания и контекстных преобразований. Она ничего не «поняла» о луке — только выбрала строки массива.

### Задание 1.3. Параметры и активации

В таблице `4 × 3` находятся 12 чисел. А результат lookup для четырёх ID содержит ещё 12 значений. Значит ли это, что у модели появилось 12 новых обучаемых параметров?

Подсказка: параметры хранятся в таблице, а вычисленный результат используется при обработке конкретного входа. Это связь с уроком 1.2.

## Эксперимент 2. Одна карта для текстов и вопроса (20–25 минут)

```bash
uv run python $P/02_local_embeddings.py
```

Программа делает **один локальный пакетный запрос**: пять документов и один вопрос. Затем все сравнения считает NumPy, а не языковая модель. Генерации текстового ответа здесь нет.

Для Qwen3 Embedding скрипт добавляет к вопросу инструкцию поисковой задачи, а документы кодирует без неё. Если меняешь модель через `MODEL_EMBED` в `.env`, сначала проверь её собственные требования к запросам и документам.

### Что смотреть

1. **Матрица `(6, 1024)`**: шесть текстов, каждый описан 1024 числами для модели по умолчанию.
2. **Нормы около единицы**: модель уже выдаёт нормализованные векторы. Код всё равно явно нормализует их для вычисления косинуса.
3. **Сравнение двух пар инструкций**: перефразировка и противоречие.
4. **Рейтинг документов для вопроса**: результат поиска кандидатов, не ответ на вопрос.
5. **Масштабирование**: умножение документов на семь и вопроса на три сохраняет косинусы.

### Что получилось на проверочном запуске

- Разрешение возврата и его перефразировка: косинус примерно **0.800**.
- Разрешение возврата и запрет возврата: примерно **0.684**.
- Для вопроса «Как вернуть покупку с чеком?» запрет оказался первым с **0.756**, рядом с инструкцией о возврате с **0.753**.

Это не универсальные значения и не проценты правильности.

**В корпусе специально лежат противоречащие друг другу документы.** Без сведений об источниках и актуальности нельзя объявить один из них действующим правилом. Найденный запрет тоже относится к теме вопроса, поэтому его высокая позиция сама по себе не доказывает ошибку поиска. Но она показывает: брать первый результат и считать его истиной опасно.

## Автоматические проверки

```bash
uv run python -m unittest discover -s "$P" -v
```

Ожидается **12 тестов, OK**. Они не обращаются к Ollama и облачным сервисам.

Среди проверок:

- порядок строк при lookup и повторе ID;
- недопустимость отрицательного ID — NumPy не должен молча выбрать строку с конца;
- единичные нормы, неизменность исходного массива и отказ от нулевых векторов;
- косинус одинаковых, перпендикулярных и противоположных направлений;
- независимость косинуса от положительного масштаба;
- правильное сопоставление векторов текстам через индексы ответа API.

Прохождение тестов подтверждает учебные вычисления, **а не качество поиска на любых документах**. Для этого в модуле 7 будет отдельная система оценки.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| `Ollama не отвечает` | Запусти `open -a Ollama`, дождись запуска приложения |
| `Модель не найдена` | `ollama list`; при необходимости `ollama pull qwen3-embedding:0.6b` |
| Тайм-аут | Проверь нагрузку и доступную память; первый запуск может загружать модель с диска |
| Ошибка embeddings API | Не подставлена ли чат-модель вместо модели эмбеддингов? |
| Нулевой вектор или NaN | Не заменяй ошибку произвольным баллом: проверь входы и вычисления |
| Другие баллы или порядок | Проверь модель, её версию, префикс запроса и тексты; не считай пример универсальным эталоном |
