## Эксперимент 1. Первый вызов (10 мин)

```bash
uv run python $P/01_first_call.py
```

Сначала **прочитай код**: он короткий. Найди в нём три настройки розетки, роли сообщений и параметры.

Что смотреть в выводе:

- `finish_reason`: должно быть `stop`;
- токены: вход и выход;
- «сырой» JSON в конце: найди `choices[0].message.content` и `usage`.

**Задание 1.1. Ловим обрезку.** Поменяй `max_tokens=2000` на `max_tokens=15` и запусти снова. Что стало с ответом и с `finish_reason`?

> У reasoning-модели при маленьком лимите ответ может оказаться **совсем пустым**: все 15 токенов ушли на «размышления». Это частая ловушка в реальных проектах.

**Задание 1.2. Выключаем размышления.** Если `qwen3.5:4b` выводит 💭 размышления, верни `max_tokens=2000` и добавь в `create(...)` параметр:

```python
reasoning_effort="none",
```

Сравни число выходных токенов и время. Что изменилось?

**Задание 1.3. В облако.** Если есть ключ OpenRouter: закомментируй блок Ollama, раскомментируй блок OpenRouter и запусти. Остальной код **не меняется**: это и есть универсальная розетка.

### Мои наблюдения

```text
1.1 max_tokens=15 →
1.2 без размышлений: токенов было … стало …, время …
1.3 облако vs локально:
```

## Эксперимент 2. Модель ничего не помнит (10 мин)

```bash
uv run python $P/02_memory.py
uv run python $P/02_memory.py --provider fast     # если есть ключ OpenRouter
```

Что происходит:

1. Представляемся: «Меня зовут Алекс».
2. Новый запрос **без истории**: «Как меня зовут?» Модель не знает.
3. Тот же вопрос **с историей**. Модель знает, а входных токенов стало больше: память стоит денег.
4. **Подделка:** подсовываем историю, где модель якобы назвала нас Борисом.

Подумай:

- Во сколько раз выросли входные токены в шаге 3 по сравнению с шагом 2? Что будет на 50-м сообщении в чате?
- Поверила ли модель подделке в шаге 4? Разные модели ведут себя по-разному: сравни local и fast.
- Как подделка истории может быть **полезна** (подсказка: few-shot, урок 3.2) и **опасна** (подсказка: prompt injection, урок 3.6)?

### Мои наблюдения

```text
Токены без истории: …, с историей: …
Подделка: local → …, fast → …
```

## Эксперимент 3. Сравнение моделей (15 мин)

```bash
uv run python $P/03_compare.py
```

Опрашиваются все провайдеры, для которых есть ключ: `local` всегда, `fast` и `flagship` при наличии ключа OpenRouter, `gemini` при наличии ключа Gemini. Можно выбрать самому:

```bash
uv run python $P/03_compare.py --providers local,fast
uv run python $P/03_compare.py -q "Почему небо голубое? Одно предложение."
```

> Первый запрос к локальной модели медленный: Ollama загружает её в память. Запусти сравнение **дважды** и смотри на второй прогон.

Что сравнивать:

- **Время и ток/с.** Кто быстрее: облако или твой M4 Pro?
- **reasoning.** Сколько токенов модель потратила на размышления относительно самого ответа?
- **Цена.** Колонка «1 млн запросов» показывает, что копейки за запрос превращаются в серьёзные деньги на масштабе.
- **Качество.** Прочитай ответы. Соблюдено ли «ровно 3 предложения»? Нет ли английских слов посреди русского текста? (Маленькие модели этим грешат.)

**Задание 3.1. Проверь цену руками.** Возьми строку облачной модели: (вход × цена входа + выход × цена выхода) / 1 000 000. Совпало с колонкой «1 запрос»?

**Задание 3.2.** Задай свой вопрос, сложный для маленькой модели: логическую задачу или вопрос о редком факте. Где локальная модель «поплыла»?

> Модели по умолчанию заданы в `providers.py`. Поменять их можно без правки кода, через `.env`:
>
> ```env
> MODEL_LOCAL=qwen3.5:9b
> MODEL_FAST=deepseek/deepseek-v4.1-flash
> MODEL_FLAGSHIP=openai/gpt-6.1-sol
> ```
>
> Актуальные названия: <https://openrouter.ai/models>, <https://ollama.com/library>.

Цена руками: … (совпало? да/нет)

## 🧯 Если что-то не так

`providers.py` переводит ошибки на понятный язык. Частые случаи:

| Сообщение | Что делать |
|---|---|
| `Ollama не отвечает` | `open -a Ollama` |
| `404: модель не скачана` | `ollama pull qwen3.5:4b` |
| `404: модели «…» нет` | Модель переименовали или убрали. Выбери новую на openrouter.ai/models и задай в `.env` |
| `401: ключ отклонён` | Проверь ключ в `.env`, запусти `check_env.py --ping` |
| `402: закончился баланс` | Пополни Credits на OpenRouter |
| `ModuleNotFoundError: providers` | Запускай из корня через `uv run python $P/...`, а не из другой папки по относительному пути |
