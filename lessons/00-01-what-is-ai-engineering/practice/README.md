## Задание 1. Найди три слабости «гениального сотрудника» (15–20 мин)

Открой любой чат-ассистент (ChatGPT, Claude, Gemini или другой) и попробуй вызвать каждую из трёх проблем:

| Проблема | Что спросить (примеры) |
|---|---|
| **Не знает твоих данных** | Вопрос о внутреннем процессе твоей компании / проекта; вопрос о событии последних дней (если веб-поиск выключен) |
| **Выдумывает** | Спроси про несуществующую библиотеку, книгу или функцию так, будто она существует: «Как использовать функцию `pandas.smart_merge_v2`?» |
| **Нет рук** | Попроси сделать действие во внешней системе: «Создай задачу в моём трекере», «Проверь мою почту» |

**Подумай:** какой из четырёх рычагов (промпт / RAG / инструменты / fine-tuning) решил бы каждую из проблем?
