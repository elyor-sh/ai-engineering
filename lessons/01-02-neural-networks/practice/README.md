### Задание 1.3. Два датчика

Сравни столбцы «с ReLU» и «без ReLU». Ожидаемое правило: `00 → 0`, `01 → 1`, `10 → 1`, `11 → 0`.

Возьми один вход и вручную пройди по двум скрытым нейронам:

1. Первый считает `ReLU(a + b)`.
2. Второй считает `ReLU(a + b - 1)`.
3. Выход равен первому результату минус два вторых.

Почему без ReLU получается совсем другое правило — `2 - a - b`?

> Один неудачный набор весов без ReLU ещё не доказывает невозможность XOR для любого линейного классификатора. Общее объяснение из теории — противоположные углы квадрата нельзя разделить одной прямой.

## Эксперимент 2. Учим один нейрон (15–20 минут)

```bash
uv run python $P/02_learning.py
open $P/out/02_learning_rates.png
```

Это искусственные данные: площади в сотнях квадратных метров, цены в условных единицах. Истинное учебное правило — `цена = 2 × площадь + 1`. Реальные цены квартир по этому правилу оценивать нельзя.

Что искать в выводе:

- один шаг для одного примера: вес `0.6`, смещение `0.6`, loss уменьшается с `9` до `3.24`;
- после обучения на четырёх примерах вес близок к `2`, смещение — к `1`;
- площади `75` и `175` м² не были в обучении: модель получает их только при проверке;
- `lr=0.001` учится медленно, `0.1` уменьшает ошибку быстрее, `1.0` приводит к росту ошибки.

### Задание 2.1. Проследи цикл обучения

Найди в `train()`:

1. Прямой проход.
2. Вычисление потерь.
3. Вычисление градиентов.
4. Обновление веса и смещения.

Здесь производные для одного нейрона записаны явно в `gradients()`. Это **не реализация универсального backpropagation для глубокой сети**. Для неё понадобилось бы распространить градиенты через все слои; библиотеки вроде PyTorch делают это автоматически.

### Задание 2.2. Дай больше времени

В сравнении скоростей поменяй число шагов с `80` на `160`. Насколько продвинулся маленький шаг? Что произошло со слишком большим?

> Не делай тысячи шагов для заведомо расходящегося варианта: числа могут переполниться. Это не улучшение обучения, а его поломка.

### Задание 2.4. Обучение против инференса

Что делает строка `answers = predict(unseen, w, b)`? Меняются ли здесь `w` и `b`? А если показать модели сто новых площадей, станет ли она автоматически точнее?
